# 统一分析工作台：实现任务与证据边界

本变更采用现有 `ui/standard` 路由。本文记录本轮实际执行的视觉任务，不创建新的研究流程或 OpenSpec 仪式。完整用户契约以 `docs/research/workspace.md` 为准；检查结果以同目录 `qa.md` 及 `evidence/` 为准。

## 1. 恢复自研分析的信息结构

- **来源与目标：**恢复 `b31db504f9ca9616b5d4c8ca523cdcfdab26d8ab:shinka/webui/` 的运行浏览、比较和完整实验分析，而不是给上游白色页面换外壳。
- **不变量：**研究方向仍为首页；普通运行独立存在；网页只读；原始 `combined_score` 不冒充研究结论；后端根目录授权、私有指标和封存边界不放宽。
- **输入：**自研 `index.html`、`compare.html`、`viz_tree.html`、双语字典；当前研究工作区及只读数据接口；既有 ops-spec 设计系统。
- **实际范围：**`analysis/`、`app/src/AnalysisWorkspace.tsx`、`WorkspaceNav.tsx`、`App.tsx`、`ResearchTab.tsx`、`SpecCard.tsx`、`types.ts`、`vite.config.ts`、`vite.analysis.config.ts`，以及配套 `analysis.py`、`ui.py`、`cli.py`。上游 `shinka/webui/` 未改。
- **输出：**研究入口与运行分析同源整合；13 个主视图和 10 个详情视图；URL/原生历史保存运行、比较选择、程序与页签；实验返回原方向/假设。
- **实际检查：**带数据能力矩阵、真实研究往返、普通运行筛选/比较/后退、私有字段与派生文件真实 HTTP 回归。具体结果见 `qa.md`。
- **失败回路：**若视图缺失，回到自研源码与 API 契约核对；若身份或权限错误，先修正授权/状态边界，不用另一个界面或空状态替代能力。

## 2. 统一可读性、主题与响应布局

- **来源与目标：**沿用墨黑/Technical Paper、Inter Variable/IBM Plex Mono、方角、分隔线、橙色信号及 1480px 上限，使研究与分析成为同一工作台。
- **不变量：**不添加营销装饰；不靠颜色单独表达选中状态；宽表和宽图在自身区域滚动；主题与语言控制不重复。
- **输入：**真实填充视图、深浅主题、桌面/平板/手机视口、键盘及减少动态效果偏好。
- **实际范围：**`app/src/analysis/workbench.css`、`accessibility.js`、`runtime.js`、`app.css`，以及自研源中与原生按钮、提示对话框、页签、缺失值呈现相关的局部修改。
- **输出：**桌面双面板、窄屏纵向面板、局部图表滚动、主题一致的图表与代码区域、可见焦点、原生按钮和对话框。
- **实际检查：**1440/1024/390px 的填充 Path/代码页面、深浅主题、CSS 200% 缩放代理、键盘页签/程序选择/比较、实际文字对比度抽查与资源错误检查。截图保存在 `evidence/`。
- **失败回路：**根据实际 DOM/CSS 和截图定位到具体旧样式、滚动容器或语义控件，修正后重新测量；不以无横滚的空白截图通过检查。

## 3. 保持切换、重绘与错误状态的一致性

- **来源与目标：**选中程序、代码、树节点/祖先路径和 URL 必须指向同一个当前运行；错误和未知数据必须可辨认。
- **不变量：**迟到的 A 运行响应不能取得 B 的身份；尺寸变化不能重载数据库或清除选择；缺失成本不等于零；失败分数不成为最佳节点；没有转换器不能制造假 PDF。
- **输入：**延迟响应、真实保存的负数/失败/缺失/零成本/空库夹具、损坏提示库、原有草稿导出路径。
- **实际范围：**自研 `viz_tree.html`、`index.html`、`compare.html` 的状态/数值呈现；`analysis.py` 的严格费用、明确读取错误和 PDF 错误边界；`tests/research/test_workspace_analysis.py`；`tools/browser-automation/unified-analysis.mjs`。
- **输出：**当前运行/详情/视图渲染归属、同步选择与重绘高亮、空库恢复、明确 HTTP 错误、可复用只读浏览器回归。
- **实际检查：**A→B 乱序、代码/初始差异/图像迟到、空库增删、提示→程序键盘选择与 resize、Path 直接链接→刷新→选择→树、转换器缺失的红绿 HTTP 回归。
- **失败回路：**重放精确失败动作，修正所属状态或读接口，再跑同一路径。现有脚本由调用方提供授权运行与实际标签，不执行候选程序或调用模型。
