# 通用研究领域（research-domains）

## 为什么

所有者 2026-10-22：「我们只是一个框架，可能我们要做的事情是很宽泛的，agent 在我们框架里面自己探索」。研究循环本身已与领域无关：方向 → 假设（可证伪）→ 实验 → 质疑 → 结论（成立 / 推翻 / 证据不足）→ 下一轮先读笔记本，所有者只在选假设、开下一轮与开封存段时介入（`docs/research/design.md` §3–4，research-agent 变更）。但每一步的具体实现都写死在量化上：

- **数据：** `DataSplit`（`notebook.py:93-116`）只描述按时间排序的 K 线文件，`prepare_data`（`scaffold.py:61-94`）只会切 CSV 尾段作封存段。
- **评估器：** `scaffold_experiment` 只接受 `QuantConfig`，`EVALUATE_TEMPLATE` 固定调用 `run_quant_eval`，任务提示写死“量化研究员、仓位 −1…1、前视、滚动 Sharpe”（`scaffold.py:19-55`、`97-135`）；`cmd_probe` 直接调用 `run_quant_eval`（`cli.py:444-472`）。
- **判定：** `skeptic.py` 的检验与 `decide` 只认 Sharpe、DSR、子区间与 PBO。
- **评估器由谁写：** 原则 2“评估器归人，不归 LLM”要求人写每个评估器；Agent 要在任意领域探索，每个新问题都要新评估器，全靠人写会卡住探索。

路线图“之后 · 通用化”与 `docs/research/workspace.md` 第 8 项都要求先出可替换的领域评估接口设计，经所有者确认后再实现。本变更就是这份设计。

## 改什么

- **核心与领域分开：** 方向在创建时写定领域；方向批准冻结检查器、数据与运行环境，轮次授权冻结每个假设的实验计划，两者合成每个实验的冻结计划（检查器与数据文件哈希、任务提示、判定规则种类与参数、主张类型——证书型或经验型、外部已知结果与来源、运行环境哈希、预算、种子得分、提案、批准与授权编号）。数据切分、留存段、封存段、多重检验校正不再是核心的必有字段，而是领域声明的能力；经验型主张必须带隐藏实例或留存数据。
- **候选与检查器分进程：** 候选在独立子进程运行、按约定只产出产物文件；候选退出后，冻结的检查器在另一个进程只读产物打分，得分不信任候选自报。这不是操作系统沙箱（所有者定为以后再做），经验型结论标“未沙箱”。
- **判定归核心：** 一组封闭、带版本的判定规则（量化现行规则、达到目标、反例、留存段对基线）；领域与 Agent 只选用并给阈值。
- **检查器提案与批准（决定 A，按方向）：** Agent 每个方向提交一次检查器及其固定资源（量化为 `QuantConfig` 与数据），所有者批准后冻结；每个假设的实验计划（任务提示、主张类型、预算、自己的数据与隐藏实例、`prior_art`、规则与参数）随所有者授权它的轮次冻结。账本新增提案与批准两种记录，与轮次授权、封存段批准分开。
- **第二个领域：数学构造。** 以圆填充为例，检查器只读候选产出的圆心与半径，确认只重新校验保存的产物。
- **工作台：** 报告与待决事项按领域用词，显示检查器提案；量化方向保持原样。
- **许愿与联网（防茧房）：** 所有者给一句话愿望与预算，Agent 起草 `program.md` 的方向说明与约束（预算与自主程度只由所有者写）。有网络时每个方向先联网写一份“已知情况”，离线时照常启动并记“没有外部参照”；实验计划冻结外部已知的最好结果、来源、比较方向与容差（`prior_art`），结论按容差写明差于、复现还是优于已知；资料由谁加入按 Agent 环境标记记录（协作标记，不是出处证明）；`brief` 与每轮资料库检查显示只引用自己结论的情况。不设硬性引用闸门。

## 不做（本变更）

- 调用外部系统的适配器与论文写作（所有者：本版不做）。本变更只立规则：外部产出不经冻结检查器不算证据。
- **依赖 research-agent：** 命令行的提案与批准独立可用。工作台的“批准检查器 + 授权这一轮”合并确认、网页许愿入口，以及所有者凭据（真正的安全边界），依赖 research-agent 变更未完成的 Agent 服务（其 4.2、5.1）。在那之前，验收只覆盖命令行；`grants.py`、`rounds.py` 与 Agent 页由两个变更共同改动，按 research-agent 先合入的顺序进行。
- 由第二个 Agent 自动审批检查器（所有者没有选 C）。
- 不能写成程序的研究（实地实验、问卷、纯思辨，包括所有者提到的哲学）。
