## 设计系统

根目录 `DESIGN.md`、`MOTION.md` 与 `design-system/` 描述当前上线的界面，在新界面替换旧界面的同一提交中改写；在此之前，本节与 `hifi/` 高保真样稿是新设计系统的唯一来源。

### 颜色

对比度按 WCAG 2.x 相对亮度公式对色值核算，括号内是该色在 `bg`、`rail`、`raised`、`hover`、`selected` 五种底色上的最小–最大值；图表只画在 `bg` 与 `rail` 上，得分色阶的下限按这两种底核算。要求：正文与小字至少 4.5:1；坐标刻线、输入框与复选框边框、选中指示和图中数据标记至少 3:1。色值核算不等于整页无障碍认证，渲染后的页面另行实测。

| Token | 深色（默认） | 浅色 | 用途 |
|---|---|---|---|
| `bg` | `#0a0a0b` | `#ffffff` | 页面底、图表底 |
| `rail` | `#0e0e10` | `#f6f6f7` | 导航栏、侧栏、检查器底 |
| `raised` | `#16161a` | `#ffffff` | 浮层、命令面板 |
| `hover` / `selected` | `#1c1c21` / `#232329` | `#efeff1` / `#e7e7ea` | 行悬停与选中 |
| `line` / `line-strong` | `rgba(255,255,255,.08)` / `.16` | `rgba(0,0,0,.08)` / `.16` | 发丝分隔线与带文字按钮的边，不单独承载信息 |
| `text` | `#ededef`（13.36–16.93） | `#18181b`（14.36–17.72） | 正文、数字、焦点环 |
| `muted` | `#a1a1aa`（6.10–7.72） | `#52525b`（6.26–7.73） | 次要文字 |
| `faint` | `#8a8a93`（4.57–5.78） | `#66666f`（4.61–5.68） | 编号、时间、标注 |
| `signal` | `#f2622e`（4.88–6.18），文字与图形共用 | 文字 `#b83e0b`（4.56–5.63），图形 `#e3550c`（3.05–3.77） | 唯一强调色 |
| `stroke` | `#6d6d76`（3.05–3.86） | `#82828b`（3.09–3.81） | 坐标轴与有数值含义的刻线、输入框与复选框边框、分段控件选中描边 |
| `grid` | `#34343b` | `#d4d4d8` | 辅助网格线；刻度值另有文字标注，不靠它读数 |
| 得分色阶 | `#606066`（`bg`/`rail` 上 ≥3.09） → `#f1f1f3` | `#8d8d90`（`bg`/`rail` 上 ≥3.06） → `#18181b` | 谱系与解空间的得分明暗；最低分的点也看得见 |

信号橙只表示“需要注意的证据”：越过噪声线的一段、最佳程序的祖先链、超预算、评估失败。没有第二种强调色，不用装饰渐变、玻璃拟态或无意义图标。

### 字体与数字

- 界面 Inter Variable，数字、编号与代码 IBM Plex Mono，均本地打包；中文回退 PingFang SC、Microsoft YaHei、Noto Sans SC。
- 字号：页面标题 26/34（590），数据句标题 30/40（600），区块标题 15/22（590），正文 13/20，小字 12/18，数字 12–13 tabular 右对齐。
- 格式：分数与 Sharpe 两位小数，DSR 三位，金额 `$0.00`，时间 `YYYY-MM-DD HH:MM` 并标注 UTC，缺失 `—`，明确记录的零显示为零。

### 空间与形状

4px 基线；间距 4、8、12、16、20、24、32、40。控件圆角 6px，浮层 8px，表格与面板不加圆角、以发丝线分隔，不用阴影分层。

### 状态

假设状态用形状加文字，从不只靠颜色；用词固定为 待跑、已选、运行中、待判定、成立、否定、未定、已确认、未确认、放弃（与当前 `app/src/format.ts` 一致）。桌面表格单元格显示形状、文字与计数；图例只作补充。英文界面对应 queued、selected、running、challenged、supported、refuted、inconclusive、confirmed、unconfirmed、dropped。

### 控件状态

选中状态不只靠底色：导航当前项与视图页签加 2px `text` 色指示条，分段控件（主题、语言）的选中段用 `text` 文字加 1px `stroke` 描边；运行表勾选框与输入框的边框用 `stroke`；带文字的按钮只用 `line-strong` 发丝边，由文字标识控件。焦点环为 2px `text` 色外描边，在选中底上仍有 13.36:1（深）与 14.36:1（浅）。

### 图表语法

- 全部为 SVG/D3，颜色取自 token；3D 聚类是按需加载的 Canvas 2D 投影。
- 要互相比较的图共用刻度并标注刻度值：首页证据刻度各行共用一把尺；进展小图组共用横轴（代数）与各自标注的纵轴。
- 噪声线由图表本身绘制；试验序号与代数只出现整数刻度。
- 评估失败在得分轴下方单列一条“失败带”，计入总数、不计入最佳与前沿，不画在 0 上。
- 图中任何悬停信息都能通过点按或聚焦在检查器中读到。

## 信息架构

单页应用，查询参数路由（沿用当前 `App.tsx` 的方式，服务端无需新增回退路由）：

| 页面 | URL | 内容 |
|---|---|---|
| 研究方向总览 | `/?view=directions` | 数据句标题；KPI 行；可排序方向表（状态、假设分布、共用刻度的证据、试验、预算、封存段、最近活动）；右栏动态 |
| 方向研究报告 | `/?view=direction&direction=…&hypothesis=…` | 主张 → 试验与噪声线 → 检查台账 → 判词；每个实验进入分析 |
| 全部运行 | `/?view=runs&q=…&sort=…&select=…` | 运行表、检索、排序、勾选；勾选两个以上进入比较 |
| 多运行比较 | `/?view=compare&runs=…` | 复用“对比”视图组件 |
| 实验分析 | `/?view=run&run=…&tab=lineage|progress|space|contest&program=…&pane=…&gen=…` | 四个联动视图与常驻检查器 |
| 资料库 | `/?view=library&page=…` | 索引、日志、待处理、wiki 正文（净化 Markdown） |

外壳：左侧导航栏（研究方向、全部运行、资料库与方向列表；1024–1279 宽与分析页折叠为带文字的窄栏）；顶栏（面包屑、视图页签、“最后更新”指示、主题与语言切换、Ctrl K 命令面板）。

## 联动与选择

分析页共享一个选择模型：`{ run, tab, program, generations, filters, pane }`，全部写入 URL。任一视图选中程序只更新检查器，并在其他视图高亮同一程序及其祖先路径，不切换当前视图（OD-11）。谱系与进展共用代数轴和代数滑杆；回放只在点击播放时按代步进，到最后一代停止（OD-8）。

检查器标签页：代码、差异、评估（输出与图像，失败明确标注）、LLM 记录、元分析总结（OD-3），以及纯文本下载（OD-12）。桌面为右侧栏（≥1440 宽 440px，1024–1439 宽 380px），手机为底部抽屉：轻点先以摘要高度弹出，上拉看完整标签页（OD-16）。

## 动效

静态姿态：没有入场动画，内容不被入场效果隐藏；状态变化即时完成；悬停与焦点只改变颜色或描边。代数回放是用户触发的离散步进，不做插值；系统要求减少动态时，回放改为每次点击前进一代。

## 无障碍与国际化

- 键盘：Tab 顺序与视觉顺序一致；表格行可用方向键移动、回车进入；Ctrl K 打开命令面板；Esc 关闭浮层与抽屉；焦点环用 `text` 色 2px 外描边。
- Carbon React 提供表格、页签、浮层、提示与展开组件的 ARIA 与键盘行为；外观全部由项目 token 覆盖。
- 中英切换覆盖全部界面文字、状态词、日期说明与图表标注；研究内容（假设标题、日志正文、LLM 输出）保持原文。默认语言暂按 grill.md:10 取中文，待所有者在高保真评审时确认。

## 数据接口

- `/api/workspace` 为每个成功方向增加只读 `evidence`（假设状态计数、最佳样本内分数、当时噪声线、失败试验数、最近活动），首页不再逐方向请求 `/api/snapshot`（`research-workspace-ui` 规格）。
- `/api/snapshot` 的 `trial_points` 增加程序编号，供试验点打开检查器（OD-18）；验证段与封存段数字仍按规则隐藏。
- 分析数据沿用 `analysis.py` 的只读接口（`/list_databases`、`/get_programs`、`/get_program_details`、元分析与图像），路径约束、私有指标隐藏与错误语义不变；只在新视图确需时增加只读聚合接口。

## 迁移与删除

按能力组替换：首页与报告 → 全部运行与比较 → 谱系 → 进展 → 解空间 → 对比 → 资料库。每组在能力对照表全部条目经新界面实测可答后，删除对应旧代码与入口（旧 iframe 工作台、`/viz_tree.html`、`/analysis/*`、`vite.analysis.config.ts`、Astro 依赖、Plotly 与 Chart.js），不保留兼容跳转。

## 风险

- 中英切换使验收矩阵翻倍（4 种宽度 × 2 套主题 × 2 种语言）；英文较长，密集表格列宽需按英文校准。
- 方向试验数按 brief.md:43 更正后的 0–5,000 设计：数字列按 5 位等宽数字预留宽度，图表横轴按试验序号或代数取整数刻度；首页表格还需在 0 个方向与 20 个方向时实测。
- 管线 `state.json` 在本阶段重置时丢失所有者的交付与评审委派，交付门禁前必须恢复（`owner-decisions.md` › 验收与委派）。
