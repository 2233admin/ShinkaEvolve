# Brief：Shinka Research 统一工作区重做

所有者 2026-10-19 的选择原文记录在 `../../../brief.md` 与 `../../../.design-pipeline/state.json`。本文把它展开为设计与验收可用的简报。

## Goal

研究者打开页面即可读懂每个研究方向的进展与证据，并能从任一结论连续进入对应实验的谱系、代码与指标；视觉与交互达到可角逐 Awwwards / Webby / FWA 的水准。奖项与所有者验收不得自授。

## Audience

所有者（量化与算法研究者，中文为主，桌面为主）及其分享结果的对象（技术读者，可能第一次接触 Shinka Research）。

## Visitor mode

- 研究页：Read——读报告、核对证据与判词。
- 运行与分析：Operate——检索、比较、选择程序、查看代码与差异。

## Surface

- 页面：研究方向总览（首页）、方向研究报告（含假设）、共享资料库、全部运行（列表与比较）、实验分析（谱系、进展、解空间、对比四个联动视图与程序检查器）。
- 组件：导航与命令面板、方向状态、证据刻度、试验与前沿图、检查台账、判词、事件、资料阅读、运行表、程序检查器（元数据、代码、差异、评估输出与图像、LLM 记录、草稿与 meta）、图表族。
- 状态：加载；空（新方向、空运行库）；错误（不可读库、越权、未知 ID）；评估失败；费用缺失；封存段未开与已开；超预算；单样本统计未知。
- 尺寸：1920、1440、1024、390 宽；深浅两套主题；200% 缩放。

## Constraints

- 只读：不提供任何写入研究状态的控件。
- 移除 Astro UXDS；Carbon 只承担交互与无障碍行为。
- 保留全部现有能力（13 个主视图、10 个详情视图、运行列表、多运行比较、研究页、资料库）；合并以所有者审阅的能力对照表为准。
- 安全边界：路径限制、私有指标隐藏、PDF 停用、不可信文本净化。
- 中文优先，遵守 CJK 排版规则；字体与资源本地打包，不依赖外网。
- 新代码只放在 AGENTS.md 允许的目录。

## Non-goals

- 运行研究、调用模型或付费服务；修改研究引擎、评估器或 notebook 格式。
- 营销落地页式装饰，与数据无关的动效。
- 修改上游 `shinka/webui/`。

## Real content ranges

- 方向 0–20 个；每个方向假设 0–10 个，每个假设实验 0–5 个；每个运行（实验）程序 0–2,000 个；代数 0–100；岛屿 1–8 个；模型 1–6 个；提示 0–50 个。
- 方向试验数 N 是该方向全部实验评估过的变体之和（含试探，即 DSR 的多重检验基数），因此是 0 到数千次：演示数据 d2 = 240 + 160 + 1 次试探 = 401。界面与刻度按 0–5,000 设计。（2026-10-19 更正：原写“试验 0–200 次”与下一条每个实验 150–400 个程序矛盾。）
- 标题中英混排，4–60 字；代码 10–2000 行；LLM 输出含 Markdown 与可能的恶意 HTML。
- 演示数据：4 个方向（进行中、已结论且封存段已开、新建无试验、超预算或含评估失败），每个有试验的实验 150–400 个程序；5 个普通运行，含空库与约 500 个程序的大库。

## Acceptance checks

- 首屏即可回答：有哪些方向，各处于什么状态，证据是否超过噪声，预算与封存段情况。证据来自 `/api/workspace` 新增的只读方向证据摘要（假设状态计数、当前最佳记录与当时的噪声线、最近活动时间、失败试验数），由 `research-workspace-ui` 规格定义并有 HTTP 回归；首页不得逐方向请求 `/api/snapshot`。
- 从任一假设两步内到达对应实验的谱系与最佳程序代码，返回时保留上下文。
- 能力对照表的每一行在新界面中实测可答。
- 1920、1440、1024、390 宽与深浅主题下无截断、遮挡与横向溢出；图表像素非空；试验序号为整数刻度。
- 键盘可达、焦点可见；正文对比度不低于 4.5，大字与图形不低于 3；axe 无严重问题；控制台零错误。
- 本机测得并记录 LCP、INP 与包体；3D 视图按需加载。
- 管线门禁（方向样稿、组件适配、反模板评审、交互探针、评分表）实际执行并留证；所有者评审绑定输出版本。

## Playground applicability

需要：设计系统 token、组件状态与图表族在深浅主题下的可视预览页，替换现有 `design-system/` 预览。
