# EvolutionLedger

The experiment page's record of what evolution actually changed: one entry per improvement on the best path, oldest first.

- Margin: 第 <g> 代 in `entry-id` and the in-sample score (样本内 1.48).
- Main: the patch name in `entry-title`, its description in `body-md`, then `Toggle` 展开改动 revealing a `Diff`.
- Under the ledger: `Toggle` 最优程序 revealing a `CodeBlock`; then the plain link 完整进化树、岛屿与嵌入（Shinka 界面）→ to the upstream view.
- In-sample scores only: this is search history, not evidence. Validation figures belong to the hypothesis entry after the verdict.
