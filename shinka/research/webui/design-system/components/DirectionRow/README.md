# DirectionRow

One research direction on the workspace page; the whole row links to the direction page.

- Margin: the direction folder name. Main: the question in `entry-title`; one `data-md` line — N · 预算 · lockbox state; then a tally of statuses written as `StatusStamp` + count, zero counts left out.
- Order directions by most recent event, newest first.
- A direction without hypotheses reads 还没有假设 in the tally line.
