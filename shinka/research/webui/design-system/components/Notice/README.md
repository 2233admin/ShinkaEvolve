# Notice

Empty and error states, written as a notebook line — never an illustration or a banner.

- Empty (`ink-secondary`): what is missing and the CLI that creates it, e.g. 还没有假设——用 `shinka_research hypothesis add` 添加。 / 还没有切分数据——第一次 `scaffold` 时切出 lockbox。 / 资料库是空的——把资料放进 `library/raw/`。 / 还没有可画的试验。
- Error (`refuted`): the unreadable file and the reason, e.g. 无法读取 `experiments/h002/e01/results/programs.sqlite`：文件不存在。
- Commands in `code` type. No icons, no exclamation marks.
