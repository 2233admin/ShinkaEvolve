# LockboxSeal

The one round shape in the system: a 26px ring (`radius-seal`) with one serif character, then a short line.

- 封 in `refuted` + 未启封 · 自 <date>: the lockbox exists and nobody has seen it.
- 启 in `ink-muted` + 已启封 · <date>: `confirm` has run; the lockbox figures may now appear.
- Before the first scaffold there is no lockbox: write 未切分 as plain `ink-muted` text, no ring.
- Never make it clickable. Opening the lockbox happens only through `shinka_research confirm`.
